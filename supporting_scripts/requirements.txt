# Land cover for the based_on_lulc source/sink method (optional — only needed
# when ss_method = "based_on_lulc").
#   * earthengine-api : GEE-based LULC sources (modis, nlcd, usda_cdl, aafc_aci,
#       worldcover, corine, nalcms, ...). Computes area-per-HRU server-side.
#       One-time auth required:  earthengine authenticate
#       (set EARTHENGINE_PROJECT to your Google Cloud project id if prompted).
#   * cdsapi : the legacy "copernicus" (ESA CCI) LULC source, auto-downloaded
#       from the Copernicus Climate Data Store (needs a ~/.cdsapirc API key).

# across both. The markers below pick the right one automatically.
